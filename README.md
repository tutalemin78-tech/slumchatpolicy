# 🛡 АНТИСНОС v6 — Защитник чата & Тролль-бот

## 🚀 Запуск:
```bash
python bot.py
```

---

## ⚡ Все новые возможности:

1. **Тихое наказание при рейде (без текста "мут навсегда")**:
   - При спаме "бан" или "кик" (3+ за 1 мин) бот **тихо** снимает с рейдера права админа и дает мут/бан (настраивается в ЛС).
   - Лишний текст в чат не шлет, а подробный лог нарушителя отправляет тебе в ЛС.

2. **Моментальный Анти-Ирис (кик неактив)**:
   - Как только кто-то пишет в чате `.кик неактив`, `!кик неактив`, `.кик неактив сутки` и т.д. — бот **мгновенно отбирает все права у Ириса**, не дожидаясь ни одного кика! Ирис физически не успеет кикнуть ни одного человека.

3. **Спам одинаковыми сообщениями (10+ за 10 сек)**:
   - Бот мутит человека и реплаем пишет: `@glicu` (текст настраивается в ЛС).
   - **РАЗНЫЕ сообщения не мутит никогда**, даже если человек отправил 100 разных сообщений за 10 сек!

4. **Спам медиа (10+ за 10 сек)**:
   - 10+ стикеров, гифок или фото за 10 секунд -> мут + ответ `@glicu`.

5. **Пользовательские триггеры автоответов**:
   - В ЛС с ботом (`/start` -> чат -> `Триггеры`) можно добавлять свои слова и ответы на них.

6. **Команда `/add` (ТОЛЬКО ДЛЯ ТЕБЯ - OWNER_ID)**:
   - Никто другой вызвать команду не может.
   - `/add [префикс]` (реплаем) — админка без прав (только инвайты).
   - `/add [префикс] full` (реплаем) — выдает **АБСОЛЮТНО ВСЕ ПРАВА** админа!

7. **Справка в боте**:
   - В ЛС по кнопке `📖 Справка` есть подробное описание каждой функции.
